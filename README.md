# Cultive-Mobile

Depois de clonar o repositório na sua IDE: 

Execute primeiro 'npm install' no terminal dentro da pasta do projeto para instalar as dependencias. 

Para rodar o projeto, execute no terminal 'npx expo start', ou 'npx expo start -c' para limpar os caches e redefinir rotas.

Após a execução, escolhe em qual plataforma deseja abir o projeto, no dispositivo mobile com Expo GO instalado previamente no aparelho mobile ou WEB com o link do localhost.
